# Personal Website with AI Chatbot

## Overview

This project is a simple personal website combined with a local AI chatbot.  It provides information abiut myself and allows you to interact with an AI model directly, all without relying on external services.

## Features

*   **Personal Website:** A basic website to showcase my content, projects, or information.
*   **Local AI Chatbot:**  An AI chatbot runs directly on my machine, providing a private and self-contained interaction.
*   **Login System:** Access the AI chatbot feature through a secure login system.
